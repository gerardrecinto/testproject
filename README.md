# Test Project — Java

Small Java sandbox project used for experimenting with language features, build tools, and IDE setup during university coursework.

![Java](https://img.shields.io/badge/Java-8%2B-007396?logo=openjdk&logoColor=white)

## Running

```bash
javac Main.java
java Main
```

Or import into IntelliJ IDEA or Eclipse and run the `Main` class directly.
